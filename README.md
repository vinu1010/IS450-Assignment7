## Description
This program is a number guessing game. The computer picks a random number
between 1 and 20, and the player has 5 tries to guess it. After each guess the
program says whether the guess was too high or low When the game ends it
prints a summary of every guess that was made.

## Input
- A number between 1 and 20, typed by the player.
- Invalid entries like letters or numbers above or below are rejected and do not use up a try

## Output
- Hints: ("Too high!" / "Too low!"), after each guess.
- A win or lose message
- A summary of all guesses and how many tries were used

## How to Run
1. Install Python 
2. Clone this repository
3. Open a terminal in the project folder
4. Run: python myProgram.py
